проверка, которую видит Яндекс Браузер

Демонстрация виджета kremle-widget: тот же протокол и тот же шаблон, что в Flask/Django/FastAPI. Без установки, без аккаунтов и без сервера — вопросы и ответы зашиты в страницу. Документация →

Это демо, а не защита. Правильные ответы лежат в коде страницы — любой, кто умеет открыть исходник, их увидит. Настоящая капча проверяет ответы на сервере (POST /kremle/verify), а правильные варианты не покидают сервер вообще. Показать демо человеку, который не пользуется Яндекс Браузером, можно прямо здесь.
Сатира на государственнический текст — в README проекта; технические утверждения этой страницы — правда, их проверяет CI.
