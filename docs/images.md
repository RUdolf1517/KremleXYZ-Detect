# Задания с рисунком

> «Задачу без картинки решает только тот, кто её придумал. Остальным нужен
> рисунок.»

Часть заданий «Решу ЕГЭ» без картинки не имеет смысла. По умолчанию такие задания
**отбрасываются**: горячие ссылки на портал не должны попадать в капчу молча.

```bash
kremle-detect questions sync --images
```

```python
kremle = KremleFlask(app, questions_source='sdamgia', questions_images=True)
```

```python
# Django
KREMLE_QUESTIONS_IMAGES = True
```

Тогда в JSON капчи у вопроса появляется `images`:

```jsonc
{"q": "На рисунке изображён график…", "opts": ["3", "4", "5", "6"],
 "images": [{"url": "https://math-ege.sdamgia.ru/img/1.png", "alt": ""}]}
```

Шаблон капчи и React-компонент рисуют их с `referrerPolicy="no-referrer"`; если
портал не отдаёт картинку, вместо неё появляется «[рисунок не загрузился]» —
капча не ломается.

## Локальный кеш картинок

Горячая ссылка работает, пока портал отдаёт файл посторонним сайтам, и каждый
показ капчи сообщает порталу IP посетителя. Чтобы этого не было, рисунки можно
скачать заранее — они лягут в `~/.cache/kremle-detect/images/<sha256>` (тот же
каталог, что и кеш вопросов; переопределяется `KREMLE_CACHE_DIR`):

```bash
kremle-detect questions sync -c math -n 30 --images --download
kremle-detect questions cache        # покажет, сколько рисунков и сколько места
```

`--download` сам включает `--images`, качает только новые файлы (повторный запуск
ничего не перекачивает, `--force-images` — перекачать) и не падает, если часть
картинок недоступна: такие задания останутся с горячей ссылкой.

Кеш рисунков, в отличие от кеша вопросов, не имеет срока жизни: задание могло
исчезнуть с портала, а файл останется. Место возвращается вручную:

```bash
kremle-detect questions images                 # сколько файлов и байт
kremle-detect questions images --prune 200     # оставить не больше 200 МиБ (удаляет старые)
kremle-detect questions images --clear         # удалить всё
```

## Настройки интеграций

```python
KremleFlask(
    app,
    questions_images=True,
    images_cache_dir='/var/cache/kremle/images',
    images_prefix='/kremle/img/',
)
```

Django: `KREMLE_IMAGES_CACHE_DIR`, `KREMLE_IMAGES_PREFIX`.

## Как проверить картинки в браузере (Яндекс не нужен)

Капча не спрятана за детекцией: `/kremle/challenge` выдаёт задание любому клиенту,
поэтому смотреть её можно в обычном Chrome/Firefox.

**Вариант 1 — совсем без сети.** Встроенное задание, рисунок нарисован SVG прямо
внутри страницы (data-URI):

```bash
kremle-detect serve --sample-image
# открыть http://localhost:8000/kremle/challenge
```

**Вариант 2 — настоящие задания портала.** Сначала скачиваем задания с рисунками
в кеш, потом запускаем демо с ними:

```bash
kremle-detect questions sync -c math -n 30 --images
kremle-detect serve --images
# открыть http://localhost:8000/kremle/challenge
```

Каждый заход на `/kremle/challenge` — новый набор вопросов, так что можно
перезагружать страницу, пока не попадётся задание с рисунком. Те же флаги через
окружение: `KREMLE_QUESTIONS_IMAGES=1`, `KREMLE_DEMO_SAMPLE_IMAGE=1`.

**Вариант 3 — без браузера, один вопрос в терминале:**

```bash
kremle-detect questions check 314159 --images   # условие, ответ и URL картинок
curl -s localhost:8000/kremle/challenge -H 'Accept: application/json' | python -m json.tool
```

В JSON картинки лежат в `questions[].images[].url` — по этим ссылкам видно, что
портал их отдаёт (в браузере они грузятся без referrer).

## Безопасность загрузки

Скачивание разрешено только по `http(s)` и только с внешних адресов: `localhost`,
приватные, link-local (включая `169.254.169.254`), loopback и `::1` отклоняются на
**каждом** редиректе. Принимаются только `image/*` (по заголовку и по сигнатуре
файла), размер ограничен 3 МиБ. Роут `/kremle/img/<key>` валидирует ключ регуляркой
`[0-9a-f]{32}` — выйти за пределы каталога кеша нельзя.
