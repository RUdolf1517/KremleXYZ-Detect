# Вопросы

> «Задания берём у классиков: портал Гущина — наше всё. Тридцать лет он
> приучает школьников к порядку, приучит и ботов.»

Источник по умолчанию (`questions_source='auto'`): **кеш заданий «Решу ЕГЭ»**,
если он есть, иначе встроенный банк. Так капча работает и без сети, и с
настоящими заданиями.

| Значение | Что берёт |
|---|---|
| `auto` | кеш «Решу ЕГЭ», если есть; иначе встроенный банк |
| `builtin` | только встроенные вопросы |
| `sdamgia` | только кеш портала |

Переключатель «свои / портал / оба вместе» — в [роадмапе](https://github.com/RUdolf1517/KremleXYZ-Detect/blob/main/ROADMAP.md)
(2.11, [issue #34](https://github.com/RUdolf1517/KremleXYZ-Detect/issues/34)).

## Встроенный банк

| Категория | Описание | Вопросов |
|---|---|---|
| `math` | профильная математика | 15 |
| `physics` | физика | 15 |
| `russian` | каверзные вопросы по русскому | 15 |
| `literature` | русская литература | 15 |

60 вопросов, по 4 варианта ответа. Это fallback, а не основной источник: банк
маленький, при `question_count=15` ротация невозможна, и бот, один раз
посмотревший ответы, проходит всегда.

```bash
kremle-detect questions --category math --count 5
kremle-detect questions -c math -n 3 --source builtin
```

Встроенный банк — это подстраховка, как свеча в ящике стола: свет не
государственный, зато в нужный момент горит.

## «Решу ЕГЭ»

```bash
kremle-detect questions sync                      # все категории, до 60 на категорию
kremle-detect questions sync -c math -n 100       # только математика
kremle-detect questions sync --ids 1001,1002      # конкретные задания
kremle-detect questions sync --images             # сохранять задания с рисунком
kremle-detect questions cache                     # что уже в кеше
```

Провайдер запрашивает `newapi/general`, открывает страницы вариантов и собирает
ссылки на задания, затем читает `/problem?id=<id>` и разбирает условие и ответ.
Числовой ответ становится правильным вариантом, три остальных — правдоподобные
искажения.

Если вариант состоит из непригодных заданий (текстовый ответ, слишком длинное
условие, «задание не найдено»), перебор ближайших id продолжается, пока не
наберётся нужное количество. Явно указанные `--ids` не разбавляются.

**Атрибуция обязательна.** Задания портала — чужой контент: подпись «Задания:
РешуЕГЭ» со ссылкой на источник уже включена в шаблон и React-компонент. Не
убирайте её.

## «А это задание вообще годится?»

```bash
kremle-detect questions check 1001
kremle-detect questions check 314159 -c physics --json
```

Скачивает одно задание, показывает, что из него получилось: текст, варианты,
какой признан верным, сколько осталось от лимита длины, есть ли картинки.
`--json` — для CI и скриптов.

## Задания с рисунком

По умолчанию **выключены**: часть заданий без картинки не решается, поэтому
такие задания раньше молча терялись.

```bash
kremle-detect questions sync --images               # сохранить задания с рисунком
kremle-detect questions sync --download             # + скачать картинки в кеш
```

При `--download` картинки кладутся в локальный кеш
(`~/.cache/kremle-detect/images/<sha256>`), и клиент получает ссылку на ваш роут
`/kremle/img/<key>` вместо портала. Это важно: горячая ссылка сообщает порталу
IP каждого посетителя и ломается, если портал закрыл hotlink.

```python
KremleFlask(
    app,
    questions_images=True,
    images_cache_dir='/var/cache/kremle/images',
    images_prefix='/kremle/img/',
)
```

Неудачная загрузка не роняет `sync`: картинка остаётся горячей ссылкой, а
шаблон при ошибке загрузки просто скрывает `<img>` и не ломает капчу.

## Свои вопросы

```python
MY_QUESTIONS = [
    {'q': 'Сколько будет 2 + 2?', 'opts': ['3', '4', '5', '6'], 'ans': 1},
    {'q': 'Столица России?', 'opts': ['Москва', 'Казань'], 'ans': 0},
]

KremleFlask(app, extra_questions=MY_QUESTIONS)
```

- `q` — непустая строка;
- `opts` — минимум 2 варианта;
- `ans` — индекс правильного варианта (0-based).

Формат проверяется при старте: ошибка в вопросе — `ValueError` с номером
вопроса, а не тихая поломка на середине капчи.

```python
KremleFlask(app, extra_questions=MY_QUESTIONS, only_extra=True)   # только свои
```

Варианты ответа — не пальцем в небо: числовой ответ даёт четыре правдоподобных
значения, и выбрать нужное — это уже маленький экзамен по здравому смыслу.

## Как получаются варианты ответа

Ответ приводится к числу; дистракторы — правдоподобные искажения: сдвиг на шаг,
масштаб, смена знака. Число остаётся в том же формате, что и исходный ответ
(запятая и количество знаков после точки).

Фильтр правдоподобия: для ответа-вероятности (`0,95`) варианты остаются в
`[0, 1]` — раньше предлагалось `1,90`, и такой вариант отбрасывает любой, включая
бота. К положительным ответам отрицательные не выдумываются. Если
правдоподобных вариантов не хватает, вопрос добирается остальными: лучше
неидеальный дистрактор, чем выброшенное задание.
